# 内容自适应分析与字幕校对

画面文字较多、领域术语密集、包含引用/数据，或常规通读无法消歧时读取本文件。

## 目录

1. 内容画像如何驱动校对
2. 画面文字与字幕对齐
3. 资料与外部来源核验

## 1. 内容画像如何驱动校对

从视频证据生成校对词表，不要预设主题。至少记录：

- 人物、机构、品牌、产品、地名、作品、章节、术语、代码符号和缩写。
- 画面标题、姓名条、字幕条、UI、幻灯片、白板、文档、网页和片尾名单。
- 明示或疑似引用的来源、版本、日期和语言。
- 数字、单位、型号、日期、网址和专有大小写。

根据画像选择证据：屏幕录制优先 UI/代码；访谈优先姓名条和官方人物资料；产品演示优先官方文档；
学术或历史引用优先原始文献/权威版本；普通口播优先音频语义和一致的专名词表。

## 2. 画面文字与字幕对齐

### 2.1 抽取代表场景

内容分析阶段可以从原片抽帧；字幕校对阶段必须从与最终字幕相同时间轴的视频抽帧：

```bash
bash scripts/extract_scene_frames.sh edited.mp4 scene_frames/ 0.3
```

脚本生成带毫秒时间戳的 `frame_*.jpg` 和 `scene_frames/frames.json`。先看数量和内容：

- 场景太少、漏掉轻微页面变化：降低阈值到约 0.2。
- 运动镜头、鼠标、动画导致帧太多：提高到约 0.4–0.5，或只对画面稳定区间使用。
- 一段没有可读文字：跳过视觉校对，不能为了完整而强行 OCR。

用视觉读取帧，照抄屏幕原样并标注置信度。竖排文字注明阅读方向；繁体、异体和大小写不要在
誊写阶段自动规范化。艺术字、低清、遮挡、公式和复杂表格若读不准，降为低置信度。

### 2.2 建立时间窗

以 `frames.json` 的 `t` 为准，窗口为 `[本帧时间, 下一帧时间)`，最后一帧结束时间取抽帧视频的
实际时长。不要重新按文件 glob 猜顺序，也不要用原片时长延长剪辑后视频的最后窗口。

把每条字幕的中点落入窗口，减少字幕跨场景边界时的误配。比对时同时查看前后相邻一帧，因为
说话者可能先说后切画面，或切换后继续上一句。

### 2.3 只把画面当“拼写证据”

只在下列条件同时成立时用屏幕文字纠错：

1. 画面文字清晰、无歧义；
2. 字幕与画面词同音/近音或明显指向同一实体；
3. 音频语义支持该实体；
4. 修改只纠正词，不改写整句。

画面可能是提纲、界面状态或编辑文案，不是逐字稿。屏幕有而口头没说，不补字幕；口头展开但
屏幕没有，不删字幕；说话者与屏幕用词不同，忠实记录实际发音并列为疑点。画面自身也可能有错字。

## 3. 资料与外部来源核验

优先级：

1. 用户提供的脚本、术语表、课件、品牌规范或正式字幕。
2. 视频同时间轴上的清晰文字和音频。
3. 被视频明确指向的原始来源或官方文档。
4. 权威二手来源；无法确认时保留疑点。

需要外部核验时，根据已识别主题搜索，不要套用固定领域：

- 引文：找到原始文本和对应版本，确认上下文，不用搜索摘要替代原文。
- 人名/机构/产品：优先官网、正式出版物或权威数据库。
- 技术术语/代码：优先官方文档、标准或原始论文。
- 数字/日期：确认口头表达与屏幕、来源的版本和时间范围一致。

外部资料只能确认拼写和事实表达，不能把说话者实际说错的内容静默改成“正确观点”。事实性口误应
忠实转录并另行标注，是否修正文案由用户决定。

## 4. 修改边界与置信度

输出修改表：

| 时间戳 | 原字幕 | 建议 | 证据 | 置信度 | 处理 |
|---|---|---|---|---|---|
| 00:03:12 | 示例错词 | 示例正词 | 清晰画面标题 | 高 | 批量确认后改 |
| 00:07:45 | 可能的专名 | 候选专名 | 官方资料 + 音频 | 中 | 逐条确认 |
| 00:12:30 | 听不清 | 不改 | 画面模糊、音频遮挡 | 低 | 交用户核对 |

- 高：画面/官方资料清晰，音频语义一致，无其他合理解释。
- 中：证据可读但有版本、繁简、大小写、口误或实体歧义。
- 低：画面模糊、音频不清、仅靠模型猜测或来源不可靠。

只批量应用经过统一授权的高置信度替换；全局替换前检查该字符串在其他语境是否可能代表不同词。
中低置信度不静默修改。保留修改清单和未决项。

## 5. 特殊内容分支

- 多语言：保留原语种专名和大小写；翻译字幕与原文字幕分轨，避免把翻译润色混进转录校对。
- 代码/命令：保留大小写、符号、路径和版本号；不要用自然语言同音词替换标识符。
- 竖排/古字/繁体：按画面原样誊写证据，字幕是否规范到简体/通行字由用户偏好决定。
- 公式/表格：除非能可靠表达，不用线性 OCR 文本纠正口头字幕。
- 姓名条/片尾名单：可确认人名和职务，但名单未被说出口的部分不加入字幕。
- 表演/剧情：字幕以角色实际台词为准，舞台说明和歌词/受版权保护文本需遵守使用限制。
